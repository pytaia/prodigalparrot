# Prodigal parrot | Hard | AISec

## Информация

На одном из вечеров когда Шкипер травил свои байки, он рассказал крайне забавную историю. Когда в средиземноморье появились пираты, капитану было поручено найти их логово. Единственным способом это сделать был шпионаж за пиратским капитаном, который был крайне осмотрителен. Самая глупая и гениальная идея - подменить любимого пиратского попугая - Крюка оказалась самой действенной. Несколько недель Шкипер лично готовил своего попугая Кешу к шпионскому заданию. По возвращению, Кеша принёс сведения о месте сбора пиратов. А после их поимки, Шкипер приютил пиратского попугая Крюка. 
Всем кто не верит в эту историю, Шкипер ставит клетки с двумя попугаями и русско-попугайный словарь, ставя задачу самим разузнать какую тайну с собой принёс попугай Кеша. Хотите попробовать свои силы?

Русско-попугайный словарь, примечание: сортируйте символы в строках которые выдаёт вам попугай согласно Unicode, они часто путают порядок букв и слов.

## Описание

Обучены две идентичные языковые модели в формате ONNX. В веса второй модели математически вшит секретный флаг: каждый символ закодирован как направление в многомерном пространстве через rank-1 возмущение весовых матриц. Модель не выдаёт флаг при генерации и не имеет аномальной perplexity на нём — единственный след флага существует исключительно в структуре разности весов между двумя моделями, скрытой дополнительной ортогональной rotation и ложным доминирующим SVD-компонентом.

## Решение

Из обоих ONNX файлов извлекаются матрицы весов и вычисляется разность ΔW. Чтобы снять скрытое вращение пространства, применяется задача Прокруста к embedding-матрицам обеих моделей: orthogonal_procrustes возвращает матрицу R, которой была повёрнута embedding, — это единственный способ её восстановить, требующий обе модели одновременно. Далее для каждого флагового слоя вычисляется R, после чего SVD этой очищенной дельты выявляет доминирующий ложный компонент S и настоящий сигнал в U. Два последовательных де-поворота через R восстанавливают исходный embedding-вектор символа флага, который затем проецируется косинусным сходством на чистую embedding-таблицу? токен с максимальным сходством и есть символ флага. Повторив это для каждого из семи слоёв, участник получает набор символов, из которых собирается текст флага.
